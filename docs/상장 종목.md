# 상장 종목

하루거래소에 상장된 가상 기업 8개다. 업종마다 한 곳씩 둔다. **모든 기업, 종목 코드, 가격은 가상이며 실존 기업과 관계없다.**

| 종목 코드 | 기업 | 업종 | 전일 종가 (초기값) | 데모 뉴스 예시 |
| --- | --- | --- | --- | --- |
| `SLCN` | 하루실리콘 | 반도체 | 9,410 | 차세대 메모리 양산 돌입 |
| `ARMR` | 철갑디펜스 | 방산 | 5,440 | 수출 계약 무기한 보류 보도 |
| `NURL` | 너울조선 | 조선 | 31,250 | LNG 운반선 6척 수주 |
| `NEUL` | 늘빛원자력 | 원자력 | 21,900 | 소형 원자로 설계 인가 획득 |
| `SAEC` | 새참식품 | 식품 | 8,030 | 원재료 이물질 검출로 판매 중단 |
| `HARU` | 하루엔터 | 엔터 | 46,750 | 하루빛 월드투어 전석 매진 |
| `BRAM` | 바람모터스 | 자동차 | 17,650 | 전기차 배터리 결함으로 리콜 |
| `BYUL` | 별길항공우주 | 항공우주 | 13,000 | 자체 위성 발사 성공 |

- 하루빛은 하루엔터 소속의 가상 그룹이다. 데모 시나리오의 "하루빛 월드투어 매진" 뉴스에 쓴다.
- 전일 종가는 호가 단위(10,000원 미만 10원, 50,000원 미만 50원, 그 이상 100원)에 맞춘 값이다.
- 종목 코드는 영문 4자로, 기업 이름에서 따왔다.

## 이름을 정한 기준

- 실존 상장사와 업계 주요 기업(예: 반도체·방산·조선·원자력·자동차·항공우주 대기업)의 이름이나 약칭을 쓰지 않는다.
- 국내 원전 이름(고리, 월성, 한빛, 한울, 새울)과 국가 사업 이름(누리호 등)을 피한다.
- 가상 뉴스에서 악재가 나와도 실존 기업이 떠오르지 않도록, 실존 브랜드를 연상시키는 단어를 피한다.

## 확인 결과 (WBS 0.7, 2026-11-25)

각 이름을 웹에서 검색해 **같은 업종에서 같은 이름을 쓰는 기업이나 제품이 없음**을 확인했다.

| 후보 | 결과 |
| --- | --- |
| 하루실리콘, 철갑디펜스, 너울조선, 늘빛원자력, 새참식품, 하루엔터, 바람모터스, 별길항공우주 | 일치하는 기업·제품 없음 → 채택 |
| 밥심식품 (식품) | 곤약밥 제품 브랜드 "밥심"이 있어 제외 |
| 다온원자력 (원자력) | "다온"은 흔한 상호이고 핵융합 전원장치 상장사(다원시스)와 비슷해 제외 |

웹 검색은 상표 등록 여부를 보여 주지 않는다. 공개 전에 KIPRIS 상표 검색을 한 번 더 한다 (`docs/후속 작업.md`).
